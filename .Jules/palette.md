## 2026-03-30 - High-Contrast Focus Visible Styling in Gradio Dark Themes
**Learning:** Gradio internal CSS rules frequently strip focus outlines using `outline: none !important;` on input fields, buttons, and textareas. When using dark theme custom styling, default browser focus rings become invisible or removed entirely. Prefixing focus rules with `.gradio-container` and using high-contrast outline borders with `:focus-visible` restores keyboard accessibility across all interactive controls.
**Action:** When customizing Gradio themes, always declare `.gradio-container button:focus-visible, .gradio-container input:focus-visible, .gradio-container textarea:focus-visible, .gradio-container summary:focus-visible` with high-contrast `outline` and `box-shadow` properties using `!important`.
