## 2024-08-05 - Custom CSS and Gradio Accessibility Overrides
**Learning:** Gradio applications inject deep, custom styling with `!important` flags that frequently strip standard accessibility behaviors, specifically focus rings (`outline: none !important`). Under default configurations, keyboard-only users cannot visually track their cursor as they tab through controls. Custom styles must explicitly redeclare high-contrast focus styles with both `:focus-visible` and higher specificity (such as prefixing with `.gradio-container`) to properly override these defaults and guarantee keyboard accessibility.
**Action:** Always include `.gradio-container` in focus-state selectors and apply clear, high-contrast `:focus-visible` properties (`outline: 2px solid #e63946 !important`, `outline-offset: 2px !important`) to buttons, inputs, textareas, and interactive elements.
