## 2026-08-12 - Overriding Gradio Focus-suppression Styles
**Learning:** Gradio's internal CSS injects `outline: none !important;` on many interactive elements like textareas, inputs, buttons, and links. Standard class or tag selectors are insufficient to restore keyboard focus outlines because they don't override these high-specificity rules. To guarantee keyboard focus accessibility, custom stylesheets must use higher specificity selectors (e.g. prefixing selectors with `.gradio-container`) combined with `!important` on the custom focus-ring outline styles.
**Action:** Always wrap `:focus-visible` styles with a high-specificity prefix (such as `.gradio-container`) and use `!important` on `outline`, `outline-offset`, and `box-shadow` properties when styling Gradio-based applications.
