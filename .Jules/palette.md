## 2025-07-21 - Neon Cyberpunk High-Contrast Focus-Visible States
**Learning:** In highly customized dark/neon interfaces (like cyberpunk themes), standard browser focus indicators and default Gradio borders are extremely low-contrast or completely invisible, failing keyboard accessibility standards. Declaring explicit `:focus-visible` styles with a high-contrast theme color (such as a vibrant neon green glow) allows standard interactive tags like buttons, inputs, textareas, and links to stand out clearly during tab navigation while reinforcing the visual identity of the design system.
**Action:** Always verify keyboard accessibility on dark/neon custom themes and explicitly style standard interactive tags using a high-contrast, theme-consistent color for their `:focus-visible` state.
