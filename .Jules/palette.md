## 2025-08-10 - Custom Theme Focus Indicator Overrides in Gradio
**Learning:** When using custom dark/neon stylesheets for Gradio apps, browser-default keyboard focus indicators are often hidden, suppressed, or blend into the dark background, rendering the application inaccessible for keyboard navigation. Because Gradio's internal CSS injects `!important` styles on elements (such as `outline: none !important`), custom focus rings must use higher specificity selectors prefixed with `.gradio-container` and declare properties like `outline` and `box-shadow` with `!important` to be successfully applied.
**Action:** Always declare explicit, high-contrast `:focus-visible` outline styles with higher specificity (e.g. `.gradio-container textarea:focus-visible`) and `!important` rules to guarantee accessibility for keyboard-only users.
