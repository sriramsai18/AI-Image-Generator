## 2025-08-05 - Stable Diffusion CPU Bottlenecks and Inference Optimizations
**Learning:** Attention slicing (`enable_attention_slicing`) significantly reduces VRAM/RAM requirements at the cost of high CPU overhead (up to ~230% slowdown). On devices with sufficient memory (>=4GB), enabling this option default-wise severely degrades performance. Additionally, wrapping the forward pass inside `torch.inference_mode` is faster and more memory-efficient than `torch.no_grad` or unoptimized generation, and using `channels_last` memory format on the UNet and VAE layers maximizes performance on modern hardware.
**Action:** Always dynamically query system memory (via standard library `os.sysconf` where applicable) to conditionally enable attention slicing, leverage PyTorch's `channels_last` for convolutional neural network modules, and wrap model generation within `torch.inference_mode` contexts.
