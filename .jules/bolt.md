## 2026-07-21 - Stable Diffusion CPU Performance Slicing Bottleneck
**Learning:** In Stable Diffusion pipelines running on CPU, `pipe.enable_attention_slicing()` should only be applied when RAM is severely restricted (< 4GB). If system RAM is sufficient (>= 4GB, as in our 8GB sandbox), enabling attention slicing introduces severe CPU fragmentation and memory access overhead, causing up to a ~230% performance slowdown. By conditionally disabling attention slicing and utilizing `channels_last` memory format (`to(memory_format=torch.channels_last)`) on the heavy UNet and VAE layers along with `torch.inference_mode()`, CPU inference speed and memory footprint are substantially optimized.
**Action:** Always verify system RAM before blindly applying memory-saving model slices, and default to `channels_last` + `inference_mode` contexts for CPU-bound PyTorch model workloads to achieve maximum throughput next time.
