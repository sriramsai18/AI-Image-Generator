## 2025-08-11 - Optimization of Stable Diffusion Pipeline Inference
**Learning:** For Stable Diffusion pipelines running on CPU/GPU, several minor configuration changes yield massive performance improvements. First, attention slicing introduces massive CPU overhead (up to ~230% slowdown) on CPU setups with >=4GB of RAM, and should only be enabled when RAM is extremely constrained (<4GB). Second, formatting VAE and UNet layers using 'channels_last' memory format speeds up execution times of convolutional operations. Third, wrapping the inference loop inside 'torch.inference_mode()' yields minor overhead savings by bypassing autograd completely.
**Action:** Dynamically check RAM size before applying attention slicing, format UNet and VAE layers using `.to(memory_format=torch.channels_last)`, and wrap the pipeline call in `with torch.inference_mode():`.
