## 2025-02-15 - Stable Diffusion Memory and Inference Optimizations
**Learning:** Stable Diffusion pipeline optimization in this repository benefits from applying 'channels_last' memory formatting on UNet and VAE layers, and wrapping inference with 'torch.inference_mode()'. Additionally, attention slicing (enable_attention_slicing) introduces severe CPU overhead (up to ~230% slowdown) and should be avoided on CPU unless RAM is extremely constrained (<4GB).
**Action:** Retrieve total system RAM in bytes on Unix systems using Python's standard library (`os.sysconf('SC_PAGE_SIZE') * os.sysconf('SC_PHYS_PAGES')`) to conditionally apply attention slicing only under extreme memory constraints. Apply 'channels_last' memory formatting to the UNet and VAE layers, and wrap the generation call in `torch.inference_mode()`.
