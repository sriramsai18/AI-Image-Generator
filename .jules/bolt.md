## 2026-03-30 - Stable Diffusion Pipeline Memory and Execution Optimizations
**Learning:** In PyTorch Stable Diffusion pipelines (`diffusers`), 2D convolutions in UNet and VAE layers achieve higher throughput when explicitly formatted with `torch.channels_last` (NHWC layout). Additionally, wrapping model generation in `torch.inference_mode()` disables autograd state tracking and version counters during inference, reducing memory overhead and execution latency. Unconditionally calling `enable_attention_slicing()` on CPU introduces loop overhead that degrades inference throughput on systems with >=4GB RAM.
**Action:** Always format UNet/VAE layers to `torch.channels_last`, wrap diffusion model evaluation in `with torch.inference_mode():`, and condition attention slicing on constrained RAM (<4GB) when deploying Stable Diffusion pipelines.
