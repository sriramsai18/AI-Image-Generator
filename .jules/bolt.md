## 2026-03-01 - Optimizing Latency and CPU Bottlenecks in Stable Diffusion Pipeline
**Learning:** CPU overhead with Stable Diffusion on average machines is heavily impacted by sub-optimal attention strategies. Specifically, using `enable_attention_slicing()` by default on CPU drops performance drastically (~2.3x slowdown) because of repeated slice copying across tensor dimensions. It should only be enabled on systems with very low RAM (<4GB). Furthermore, utilizing PyTorch's `channels_last` memory format on UNet and VAE layers leverages vectorized convolutional kernels, improving tensor calculation speed. Wrapping generation inside `torch.inference_mode()` context manager rather than standard inference blocks autograd engine state-tracking overhead, reducing inference latency per step.
**Action:** Always condition memory optimizations like attention-slicing on actual available hardware parameters using standard system properties (`os.sysconf`), utilize `channels_last` memory layout for convolutional layers, and use `torch.inference_mode()` context manager instead of standard pipeline calls or `torch.no_grad()` to achieve optimal performance.
