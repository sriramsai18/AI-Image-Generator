## 2026-02-17 - CPU Attention Slicing Overhead & Inference Mode Optimizations
**Learning:** `enable_attention_slicing()` in Hugging Face Diffusers reduces peak VRAM usage by computing attention in slices, but introduces massive CPU execution overhead (up to ~230% slowdown) when running on CPU. Furthermore, wrapping diffusion pipeline calls in `torch.inference_mode()` and applying `channels_last` memory formatting to UNet and VAE modules significantly accelerates tensor convolutions and avoids unnecessary autograd graph construction.
**Action:** Always avoid default CPU attention slicing unless system RAM is severely constrained (<4GB). Ensure `torch.inference_mode()` wraps pipeline execution and apply `channels_last` memory layout on CUDA devices for spatial convolution performance wins.
