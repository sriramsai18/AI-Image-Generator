## 2026-10-01 - Optimizing Stable Diffusion Pipeline Memory Format and Inference Mode
**Learning:** PyTorch diffusion pipelines heavily rely on 2D convolutions in the UNet and VAE components. Default PyTorch memory format (`contiguous`/`NCHW`) incurs extra memory transpose operations and suboptimal kernel execution. Converting `pipe.unet` and `pipe.vae` memory layout to `torch.channels_last` (NHWC) enables optimized cuDNN/oneDNN tensor core execution for 2D convolutions. Additionally, wrapping diffusion generation in `torch.inference_mode()` bypasses PyTorch autograd tracking and tensor version counter updates entirely.
**Action:** Always format 2D CNN weights in diffusion models (UNet and VAE) to `channels_last` memory format and wrap pipeline execution within `with torch.inference_mode():` for minimum overhead.
