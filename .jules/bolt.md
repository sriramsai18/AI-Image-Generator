## 2025-07-12 - [Stable Diffusion Pipeline Optimization & Attention Slicing]
**Learning:** Optimizing Stable Diffusion memory format to 'channels_last' on UNet and VAE layers significantly improves cache locality and GPU/CPU inference performance. Furthermore, wrapping generation loops inside `torch.inference_mode()` context bypasses unnecessary gradient tracking overhead entirely. In contrast, calling `enable_attention_slicing()` on modern machines with sufficient memory (>=4GB RAM) can introduce extreme CPU bottlenecks (up to ~230% slowdown) rather than speeding up inference, so it should only be conditionally enabled under extreme RAM constraints (<4GB).
**Action:** Apply memory layout format 'channels_last' and wrap inference calls in `torch.inference_mode()`. Perform system resources verification (using `psutil`) before applying slow fallback memory-saving paths like attention slicing on CPU.
